# Portfolio David — Développeur Web

Portfolio personnel de David, développeur web congolais basé au Burundi.

## Stack

- Next.js 14 (App Router)
- TypeScript strict
- Tailwind CSS
- Framer Motion (motion)
- next-themes
- React Hook Form + Zod
- Resend

## Installation (Windows)

```powershell
# Cloner ou créer le dossier
cd david-portfolio

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev
